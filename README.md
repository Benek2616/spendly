# 💸 Spendly

Nowoczesny tracker wydatków w formie PWA.

## Funkcje
- Szybkie dodawanie wydatków
- Kategorie (Jedzenie, Transport, Zakupy, Rozrywka, Zdrowie, Inne)
- Podsumowanie miesiąca
- Podział na kategorie z paskami postępu
- Dane tylko lokalnie
- Gotowa jako PWA do instalacji i publikacji w Google Play
